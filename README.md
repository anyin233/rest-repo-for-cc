# 分布式调度系统建模

这个项目实现了一个分布式任务调度系统的仿真，比较了三种不同的调度算法在四峰分布工作负载下的性能。

## 系统模型

### 系统架构
- **n个节点**：分布式系统由n个工作节点组成
- **相同模型**：每个节点执行相同的任务处理模型
- **随机执行时间**：对于输入x，执行时间f(x)服从某个概率分布

### 调度算法

#### 1. Round Robin (轮询调度)
- **原理**：按顺序将任务依次分配到各个节点的任务队列
- **优点**：实现简单，保证负载均衡
- **缺点**：不考虑任务执行时间差异，可能导致某些队列堆积

#### 2. Shortest Queue (最短队列)
- **原理**：计算每个队列的总执行时间期望和方差，选择综合得分最低的队列
- **评分公式**：`score = E[T] + α * σ[T]`
  - E[T]：队列总时间期望
  - σ[T]：队列总时间标准差
  - α：方差权重参数（默认0.5）
- **优点**：考虑任务差异，更智能的负载均衡
- **缺点**：需要计算期望和方差，计算开销稍大

#### 3. Probabilistic (概率采样)
- **原理**：对每个队列的总时间进行采样，选择采样值最小的队列
- **实现**：为简化计算，每个队列采样一次，任务发送到采样值最低的队列
- **优点**：考虑了执行时间的随机性
- **缺点**：采样次数影响精度

## 数据集

### 四峰分布
使用高斯混合模型生成四峰分布，模拟真实系统中不同类型任务的执行时间分布：

| 峰编号 | 中位数 | 标准差 | 权重 |
|--------|--------|--------|------|
| 峰1    | 50秒   | 10秒   | 25%  |
| 峰2    | 100秒  | 15秒   | 25%  |
| 峰3    | 175秒  | 20秒   | 25%  |
| 峰4    | 375秒  | 40秒   | 25%  |

这种分布模拟了：
- **短任务**（峰1）：快速查询、简单计算
- **中等任务**（峰2-3）：标准数据处理
- **长任务**（峰4）：复杂分析、批处理

## 性能指标

系统测量以下关键性能指标：

1. **响应时间（Response Time）**
   - 平均响应时间
   - 中位数响应时间
   - P95响应时间（95%分位数）
   - P99响应时间（99%分位数）

2. **等待时间（Waiting Time）**
   - 平均等待时间
   - 中位数等待时间

3. **变异性指标**
   - 标准差
   - 最大响应时间

## 实验结果

基于1000个任务、4个节点、0.5任务/秒到达率的实验：

### 主要发现

1. **Probabilistic调度器**在平均响应时间和中位数响应时间上表现最佳
2. **Shortest Queue调度器**在P95响应时间上表现最佳
3. 三种算法的性能差异相对较小（~0.16%），说明在此工作负载下算法选择不是主要瓶颈
4. 所有算法在高负载下都能保持相对稳定的性能

### 性能对比（示例）

| 指标 | Round Robin | Shortest Queue | Probabilistic |
|------|-------------|----------------|---------------|
| 平均响应时间 | 21297.93s | 21263.65s | **21262.61s** |
| 中位数响应时间 | 21187.17s | 21100.93s | **21093.43s** |
| P95响应时间 | 39989.28s | **39837.83s** | 39856.21s |
| P99响应时间 | 41966.98s | 41375.74s | **41329.47s** |

## 技术特点

### 高效实现
1. **离散事件仿真**：使用优先队列（heapq）实现高效的事件调度
2. **O(1)队列选择**：
   - Round Robin：常数时间
   - Shortest Queue：O(n)，n为节点数
   - Probabilistic：O(n)，n为节点数
3. **内存优化**：增量更新队列统计信息，避免重复计算

### 可扩展性
- 支持自定义调度算法
- 参数化的仿真器配置
- 模块化设计，易于扩展

## 进一步研究方向

5. **实时调度**：考虑任务截止时间约束
